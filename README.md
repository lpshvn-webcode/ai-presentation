# ai-presentation

Репозиторий-хранилище презентаций: исходники в HTML и их экспорт в PDF.
Используется как база референсов для новых презентаций.

## Структура

```
html/<slug>/       — исходный HTML презентации (index.html + свои ассеты: картинки, шрифты, стили)
pdf/<slug>.pdf     — экспорт той же презентации в PDF
shared/            — общие ресурсы для всех презентаций
  css/print.css    — базовые стили для консистентного экспорта в PDF (@page, .slide)
  fonts/           — общие шрифты
  templates/       — стартовый шаблон для новой презентации
scripts/
  export-pdf.mjs   — скрипт экспорта html/<slug> -> pdf/<slug>.pdf
```

`<slug>` — короткое имя презентации в kebab-case, одинаковое в `html/` и `pdf/`,
чтобы легко находить пару html ⇄ pdf для одной и той же презентации.

## Добавление новой презентации

1. Скопировать `shared/templates/slide-deck.html` в `html/<slug>/index.html`
   (или взять за основу любую существующую презентацию из `html/` как референс)
2. `html/<slug>/assets/` — картинки, шрифты и т.п., специфичные для этой презентации
3. Экспортировать в PDF (см. ниже) → `pdf/<slug>.pdf`

## Экспорт в PDF

Каждый слайд — это блок `<section class="slide">` фиксированного размера
(1280×720, задаётся в `shared/css/print.css`), с разрывом страницы после
каждого слайда. Такой HTML одинаково хорошо превращается в PDF и вручную,
и автоматически.

**Автоматически (рекомендуется, даёт одинаковый результат каждый раз):**

```bash
npm install                       # один раз, поставит playwright
npx playwright install chromium   # один раз, поставит браузер
npm run export -- <slug>          # html/<slug>/index.html -> pdf/<slug>.pdf
```

**Вручную (быстрый вариант без установки зависимостей):**
Открыть `html/<slug>/index.html` в Chrome → Ctrl/Cmd+P → Destination:
Save as PDF → в More settings включить "Background graphics" → сохранить
в `pdf/<slug>.pdf`. Если презентация подключает `shared/css/print.css`,
размер страниц в PDF будет соответствовать размеру слайдов.
