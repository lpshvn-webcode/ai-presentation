# ai-presentation

Репозиторий-хранилище презентаций: исходники в HTML и их экспорт в PDF.
Используется как база референсов для новых презентаций.

## Структура

```
html/<slug>/            — исходный HTML презентации (index.html + assets/)
pdf/<slug>.pdf          — экспорт той же презентации в PDF
shared/
  css/deck.css          — дизайн-система: тёмные/светлые слайды 16:9, Inter, синий акцент
  js/deck.js             — навигация по слайдам (стрелки, точки, фуллскрин, печать в PDF)
  templates/slide-deck.html — стартовый шаблон новой презентации на этой системе
  references/           — исходники референсов, из которых собрана дизайн-система
scripts/
  export-pdf.mjs         — скрипт экспорта html/<slug> -> pdf/<slug>.pdf
```

`<slug>` — короткое имя презентации в kebab-case, одинаковое в `html/` и `pdf/`,
чтобы легко находить пару html ⇄ pdf для одной и той же презентации.

## Дизайн-система (`shared/css/deck.css`)

Слайд 16:9 (1280×720), тёмный или светлый фон (`.slide.dark` / `.slide.light`),
шрифт Inter, единственный акцентный цвет `--accent` (по умолчанию синий `#3B82F6`,
меняется в `:root` конкретной презентации при необходимости).

Основные блоки разметки — см. живые примеры в `shared/templates/slide-deck.html`
и в любой готовой презентации:

- `.top-row` / `.top-meta` — тонкая шапка слайда (раздел презентации)
- `.kicker` — короткий ярлык-категория над заголовком
- `h1.headline` (+ `.xl` для титульного) — заголовок, `<span class="accent">` — акцент
- `.lede` — подзаголовок-пояснение
- `.cols.cols-2/3/4` — колоночная сетка
- `.card` + `img.shot` — скриншот-доказательство в рамке
- `.callout` — блок «Рекомендация» с акцентной линией слева
- `.step-num` / `.item-title` / `.item-desc` — пронумерованный пункт
- `.stat-big` / `.stat-label` — крупная цифра для акцента на цифрах/деньгах
- `ul.plain` — список с маркерами `✓` / `→`
- `table.clean` — таблица метрик
- `.bottom-row` — нижняя строка: вывод слайда слева, номер `NN / всего` справа

Презентация на этой системе одновременно:
- **интерактивный слайд-шоу** при открытии `index.html` в браузере (стрелки,
  точки-навигация, `F` — полный экран, кнопка «PDF» — печать)
- **готовый к печати документ** — `@media print` в `deck.css` разворачивает
  все слайды в PDF-страницы 13.333×7.5in (то же 16:9)

## Добавление новой презентации

1. Скопировать `shared/templates/slide-deck.html` в `html/<slug>/index.html`
   (или взять за основу любую существующую презентацию из `html/` как референс)
2. `html/<slug>/assets/` — картинки и т.п., специфичные для этой презентации
3. Экспортировать в PDF (см. ниже) → `pdf/<slug>.pdf`

## Экспорт в PDF

```bash
npm install                       # один раз, поставит playwright
npx playwright install chromium   # один раз, поставит браузер
npm run export -- <slug>          # html/<slug>/index.html -> pdf/<slug>.pdf
```

Вручную: открыть `html/<slug>/index.html` в Chrome, нажать кнопку «🖨 PDF»
в правом верхнем углу (или Ctrl/Cmd+P) → Destination: Save as PDF → в More
settings включить «Background graphics» → сохранить в `pdf/<slug>.pdf`.
