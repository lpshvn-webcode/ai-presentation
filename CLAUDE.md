# Правила репозитория

Хранилище презентаций агентства 303.cult. Полное описание — в README.md.

- Каждая презентация — в папке `<reports|audits|cases>/<проект>/<период>/`:
  отчёты за месяц → `reports/`, аудиты → `audits/`, кейсы → `cases/`.
  Период — `ГГГГ-ММ` (для аудитов и кейсов — `ГГГГ-ММ-<тема>`).
- Готовые файлы называются `<проект>-<тип>-<период>.pdf/.html` и
  собираются только командой `npm run build -- <папка>`; имена руками не придумывать.
- `index.html` — редактируемый исходник, готовый `.html` для отправки
  собирается рядом; `source/` — исходные данные (выгрузки, скриншоты).
- Перед новым отчётом по проекту — прочитать `reports/<проект>/README.md`
  (паспорт проекта), скопировать папку прошлого месяца и сохранить её
  структуру, оформление и определения метрик. После — дописать в паспорт
  историю и всё, что изменилось.
- Логотипы: `shared/brand/303cult/`, `shared/brand/clients/<проект>/`.
